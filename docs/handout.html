Better host,
not faster clone.

Talaria is a native terminal UI that hosts Hermes Agent. We cover the agent’s jobs with our own chrome — quieter, searchable, aligned with the marketing site. If a mock looks like official Hermes with a TALARIA sticker, it is wrong.

Talaria is the frame.
Hermes is the speaker.
The transcript is a document.
Management is sheets.
Danger is modals.
Slash is power.
The palette is discovery.

Full spec (tokens, copy deck, do/don’t): DESIGN-HANDOUT.md. Engineering plan: REDESIGN.md. Names: NOTICE.md.

Two brands, one canvas

Talaria owns

Frame, composer, meter, sheets, modals, palette, wordmark TALARIA, default skin (parchment + teal).

Hermes owns

The voice in the transcript. Caduceus and ⚕ are agent marks, never our logo. Models, tools, ~/.hermes.

Never: “TALARIA - CLIENT”, “Welcome to Hermes Agent!”, “Messenger of the Digital Gods”, caduceus as hero, Nous on the splash.
Always: “Native TUI host for Hermes Agent”. Unofficial. Binary is talaria.

Medium

This is a terminal grid, not a web app. Design at 100×32 cells; must work at 80×24. Monospace only. No drop shadows, blur, or images in the TUI. Website (Archivo, ink shadow, dots) is the marketing twin — borrow palette and attitude, not CSS chrome.

Do / don’t

Design the frame first (composer, meter, empty state), then the Hermes card. Sheets with search. Danger as modals. Tools as chips + inspector. Specify 80 and 100 cols. Use token names on the mock.
Clone Ink splash, caduceus hero, chevron accordion, kaomoji status, help text under chips, GitHub Dark as brand default, drop shadows in TUI mocks, voice/billing/inline PNG (out of scope).
