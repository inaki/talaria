Talaria Agent

Native ratatui host for Hermes Agent. The UI is Rust; the agent stays Python. Binary is talaria, never hermes.

GitHub Notice MIT license Hermes Agent

Install

Needs a working Hermes Agent first (hermes --tui). Quit that TUI before starting Talaria — they share ~/.hermes.

curl -fsSL https://raw.githubusercontent.com/inaki/talaria/main/install.sh | bash
brew install inaki/talaria/talaria
talaria

What it is

  • A host, not a fork. Speaks the official tui_gateway JSON-RPC.
  • Chrome lives in ~/.talaria. Agent config stays in ~/.hermes.
  • Independent of Nous Research. See the notice before you present it as theirs.
