WHAT YOU GET

Every surface of hermes --tui, redrawn immediate-mode in ratatui.

SPLASH ANSI Shadow wordmark, Braille caduceus, and live tools and skills pulled from session.info.
CHAT Streaming deltas as they arrive, markdown on completed turns, thinking blocks inline.
TOOLS Collapsed cards by default; Ctrl+O expands args and result with secrets redacted.
APPROVALS Approval, clarify, sudo and secret overlays, each modal over the transcript.
SLASH Catalog served by the gateway, in a drop-up palette on /.
SESSIONS /sessions for saved versus live, plus /branch and /rewind with confirm_truncate.
STEER Enter while a turn is running sends session.steer instead of a new message.
SKINS github plus every Hermes builtin — default, ares, mono, slate, daylight, poseidon and more via /skin.

Full matrix: docs/PARITY.md

INSTALL

Needs a working Hermes Agent first.

Quit that TUI before starting Talaria — they share ~/.hermes. Talaria only ever writes ~/.talaria.

Homebrew macOS · builds from source

Formula tap. Compiles the crate locally, so expect a Rust toolchain and a minute of build time.

brew install inaki/talaria/talaria
talaria
curl macOS / Linux · prebuilt binary

Use this exact URL (raw.githubusercontent.com), not the GitHub file page. The binary lands in ~/.local/bin.

curl -fsSL https://raw.githubusercontent.com/inaki/talaria/main/install.sh | bash
export PATH="$HOME/.local/bin:$PATH"
~/.local/bin/talaria --version
Hermes Agent required for live mode

Install and set up the agent first, then run hermes setup. Talaria refuses to start while another tui_gateway is live.

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
hermes setup

WHAT IT IS

A host, not a fork
Speaks the official tui_gateway JSON-RPC over stdio. Python still owns tools, memory, skills and models.
Chrome stays out of the way
Logs, composer history and the saved theme live in ~/.talaria. Agent config stays in ~/.hermes. The binary is talaria, never hermes.
